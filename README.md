## Язык программирования

Исходный код на ассемблере Machina хранится в файлах `.asm` в кодировке UTF-8.

Пример из [cat.asm](examples/cat.asm)

```asm
equ PORT_INPUT, 0
equ PORT_OUTPUT, 1

section text
global _start

_start:
    IN R0, PORT_INPUT
    OUT PORT_OUTPUT, R0
    JMP _start
```

### Синтаксис

Каждая инструкция, директива или метка занимает одну строку. Метка заканчивается двоеточием,
операнды разделяются запятыми. Начальные пробелы, табуляции и пустые строки игнорируются.
Вне литерала `;` начинает комментарий до конца строки. Для мнемоник, регистров и директив регистр букв
произвольный. Для пользовательских имён он значим. Имя соответствует `[A-Za-z_][A-Za-z0-9_]*`.
Ключевые слова, мнемоники и имена регистров зарезервированы.

#### Грамматика базовой версии (EBNF)

- `::=` задаёт правило. Соседние элементы записываются последовательно.
- `[ … ]` — необязательный элемент, `{ … }` — ноль или больше повторений.
- `|` разделяет варианты, `( … )` объединяет элементы в группу.
- Кавычки обозначают буквальный текст, угловые скобки — класс символов или лексическое условие.
  Например, `"["` — символ ассемблера в записи `[R0]`, а `[ comment ]` — необязательный комментарий.

Правила строк оперируют лексемами. Пробелы и табуляции между ними игнорируются, внутри литералов сохраняются.
Конец файла завершает последнюю строку, даже если после неё нет перевода строки.

```ebnf
program     ::= { macro_def | item }
item        ::= conditional | [ label | instruction | directive | macro_call ] eol
label       ::= identifier ":"
eol         ::= [ comment ] newline
comment     ::= ";" { <любой символ, кроме CR и LF> }
newline     ::= <LF или CRLF, в том числе подразумеваемый в конце последней строки>

directive   ::= "section" ( "text" | "data" )
              | ( ".org" | "space" ) expression
              | ( "global" | "extern" ) names
              | "equ" identifier "," expression
              | ( "byte" | "word" ) expression { "," expression }
              | "pstr" string
names       ::= identifier { "," identifier }
conditional ::= "if" expression eol { item } [ "else" eol { item } ] "endif" eol
macro_def   ::= "macro" identifier [ names ] eol { template eol } "endm" eol
template    ::= { parameter | <лексема тела макроса, кроме macro, endm и комментария> }
parameter   ::= backslash identifier
macro_call  ::= identifier [ argument { "," argument } ]
argument    ::= operand | string

instruction ::= ( "HALT" | "RET" )
              | ( "JMP" | "JZ" | "JNZ" | "CALL" ) expression
              | "IN" gpr "," expression | "OUT" expression "," gpr
              | ( "MOV" | "MOVB" | "CMP" | "SUB" ) operand "," operand
operand     ::= register | expression | memory
register    ::= gpr | "PC" | "SP" | "FLAGS"
gpr         ::= "R0" | "R1" | "R2" | "R3" | "R4" | "R5" | "R6" | "R7"
memory      ::= "[" expression "]" | "[" gpr "]" [ "+" ]
              | "[" gpr ( "+" | "-" ) expression "]" | "-" "[" gpr "]"
expression  ::= product { ( "+" | "-" ) product }
product     ::= unary { "*" unary }
unary       ::= ( "+" | "-" ) unary | integer | character | identifier | "(" expression ")"

identifier  ::= ( letter | "_" ) { letter | digit | "_" }
integer     ::= digit { digit } | ( "0x" | "0X" ) hex { hex } | ( "0b" | "0B" ) bit { bit }
character   ::= "'" ( <печатный ASCII, кроме апострофа и обратной косой черты> | escape ) "'"
string      ::= '"' { <печатный ASCII, кроме двойной кавычки и обратной косой черты> | escape } '"'
escape      ::= backslash ( "n" | "r" | "t" | "0" | backslash | "'" | '"' | "x" hex hex )
backslash   ::= <символ U+005C>
letter      ::= <A–Z или a–z>
digit       ::= <0–9>
hex         ::= digit | <A–F или a–f>
bit         ::= "0" | "1"
```

После подстановки аргументов строки тела макроса разбираются по правилу `item`.
Формы операндов для первых программ приведены в разделе «Система команд».

| Директива | Семантика |
|---|---|
| `section text`, `section data` | Выбрать секцию инструкций или статических данных. |
| `.org offset` | Продвинуть позицию до указанного абсолютным выражением смещения от начала секции. |
| `byte a, …`, `word a, …` | Разместить значения последовательно, по 1 или 4 байта. |
| `space n`, `pstr "…"` | Зарезервировать `n` байтов или разместить строку с байтом длины. |
| `equ имя, выражение` | Объявить целочисленную константу текущего файла. |
| `global имя, …`, `extern имя, …` | Экспортировать свои метки или объявить ссылки на метки другого модуля. |
| `macro имя параметры` … `endm` | Подставить позиционные аргументы вместо `\параметр` в теле макроса. Параметры перечисляются через запятую. |
| `if выражение` … [`else` …] `endif` | Включить первую ветвь при ненулевом значении, иначе выбрать ветвь `else`, если она есть. |

### Семантика

- **Вычисления.** Ассемблер вычисляет константные выражения с целочисленной точностью и проверяет диапазон при записи поля. Приоритет от старшего к младшему: скобки, унарные знаки, умножение, сложение и вычитание. Бинарные операции одного приоритета выполняются слева направо. Процессор читает операнды до записи результата, арифметика выполняется по модулю `2^32`.
- **Имена.** Метки и константы разделяют пространство имён файла, у макросов своё пространство. Повторное определение запрещено. На метку можно сослаться до объявления. Константы и макросы определяются до использования. Параметры макроса видны внутри его тела. Вложенные определения макросов и рекурсивное раскрытие запрещены.
- **Адреса.** Абсолютные выражения для `equ`, `.org`, `space` и `if` могут использовать ранее объявленные константы. Адресное выражение допускает одну метку с абсолютным смещением, например `message + 1`. Компоновщик определяет итоговые адреса после размещения секций и связывает каждый импорт с единственным экспортируемым определением.
- **Типы и литералы.** Знаковую интерпретацию задаёт инструкция. Целые записываются в десятичной, шестнадцатеричной (`0x2A`) и двоичной (`0b101010`) системах. Для поля шириной `n` бит допустим диапазон от `−2^(n−1)` до `2^n−1`. Отрицательные значения хранятся в дополнительном коде.
- **Символы и строки.** Символ в одинарных кавычках занимает один байт. В литералах допустимы печатный ASCII и последовательности `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, `\xHH`. Строка в двойных кавычках содержит до 255 байтов после раскрытия этих последовательностей. Например, `pstr "Hi"` занимает три байта: `02 48 69`.

## Организация памяти

Код и данные размещаются в общей однопортовой памяти с байтовой адресацией. Адрес занимает 16 бит,
машинное слово — 32 бита. Секция `text` содержит инструкции и процедуры, `data` — статические данные.
Регистры `R0`–`R7` хранят 32-битные значения, `PC` — адрес команды, `SP` — указатель стека, `FLAGS` — флаги.

| Операнд | Значение |
|---|---|
| `Rn`, `выражение` | Значение регистра или непосредственное значение. Метка без скобок даёт адрес. |
| `[адрес]`, `[Rn]`, `[Rn ± смещение]` | Обращение к памяти по указанному или вычисленному адресу. |
| `[Rn]+` | Обращение по старому адресу, затем увеличение регистра. При чтении с последующей записью увеличение происходит после записи. |
| `-[Rn]` | Уменьшение регистра перед обращением по новому адресу. |

В адресных режимах `Rn` — один из `R0`–`R7`. Шаг изменения равен размеру доступа: 1 байт для `MOVB`, 4 для `MOV`.

## Система команд

Предварительный формат команд для `cat` и `hello` использует первое слово для кода операции,
режимов адресации, номеров регистров и порта. Непосредственное значение и абсолютный адрес занимают
по одному дополнительному слову. При выборке каждого слова `PC` продвигается на 4 байта.

| Команда | Действие | Длина, слов |
|---|---|---:|
| `IN Rn, 0` | Прочитать байт из входного потока, обнулить старшие биты регистра. При пустом потоке завершить моделирование. | 1 |
| `OUT 1, Rn` | Передать младший байт регистра в выходной поток. | 1 |
| `MOV Rn, значение` | Загрузить непосредственное значение. | 2 |
| `MOV Rd, [Rs]+`, `MOVB Rd, [Rs]+` | Загрузить слово или байт соответственно. При загрузке байта обнулить старшие биты. | 1 |
| `CMP Rn, значение`, `SUB Rn, значение` | Обновить флаги по разности. `SUB` также записывает результат в `Rn`. Флаг `Z` равен 1 при нулевом 32-битном результате. | 2 |
| `JMP адрес`, `JZ адрес`, `JNZ адрес` | Перейти по абсолютному адресу безусловно, при `Z = 1` или при `Z = 0` соответственно. | 2 |
| `CALL адрес` | Уменьшить `SP` на 4, записать по нему адрес следующей команды и перейти к процедуре. | 2 |
| `RET` | Прочитать адрес возврата по `SP` в `PC`, увеличить `SP` на 4. | 1 |
| `HALT` | Остановить процессор. | 1 |
